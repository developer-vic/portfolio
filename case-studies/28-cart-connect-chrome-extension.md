# Cart Connect Chrome Extension

![Cart Connect Chrome Extension](../images/cart-connect-chrome-extension.png)

> Shopping and chatting in one place.

CartConnect is a chat extension with a clean, modern UI inspired by the Honey extension and built closely to Figma designs.

## Features

1. Sign-up, login, profile management, and password recovery
2. Real-time chat with autosave, timestamps, color-coded bubbles, invites, sorting, and deletion
3. Product link sharing with names and images
4. Emoji icons for chats and carts
5. Home, Chat, and Settings screens with rounded elements and spacious layouts

The video shows the extension in use.

**Stack:** JavaScript, Chrome Extension, Figma.
